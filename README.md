📖 Descripción
Este repositorio contiene la digitalización y modernización del modelo de Análisis de Puestos de Trabajo (A.P.T.) desarrollado por Mª Teresa Martín González en el seno del Instituto de Pedagogía del CSIC. El modelo original, publicado en la década de 1970, fue pionero en España en la aplicación sistemática del análisis de puestos a la Formación y Orientación Profesionales.
El trabajo de campo original se aplicó a la Familia Profesional Sanitaria (Auxiliares de Clínica, Puericultoras y Cuidadores), pero la estructura del modelo es genérica y extrapolable a cualquier ocupación o sector productivo.
Objetivo de este repositorio
Convertir un documento histórico en papel en un recurso vivo, editable y aplicable en el contexto actual de la orientación profesional, la formación ocupacional y la gestión de recursos humanos.

🛠️ Cómo Usar Este Recurso
Para Orientadores y Orientadoras Profesionales

    Utiliza las hojas de Fase III para construir perfiles de ocupación detallados
    Aplica las escalas de medición para diagnosticar adecuación persona-puesto
    Adapta los factores a las ocupaciones de tu territorio o sector

Para Formadores y Formadoras

    Diseña curricula de Formación Profesional basados en las competencias reales detectadas
    Identifica brechas entre formación recibida y exigencias del puesto
    Desarrolla simulaciones y casos prácticos a partir de las tareas descritas

Para Gestores de RRHH

    Estandariza descripciones de puesto en tu organización
    Diseña procesos de selección basados en requerimientos objetivos
    Planifica carreras profesionales y itinerarios de promoción

Para Investigadores

    Replica el modelo en nuevos sectores o contextos geográficos
    Valida psicométricamente las escalas propuestas
    Contrastar con frameworks contemporáneos (O*NET, ESCO, MECU)

🔄 Actualizaciones Recomendadas
El modelo original requiere adaptaciones para el contexto actual. Las Notas de Actualización (Hoja 17 del Excel) priorizan:
Table
Prioridad	Aspecto	Acción Sugerida
🔴 Alta	Moneda en pesetas	Sustituir por euros o eliminar referencias monetarias
🔴 Alta	Competencias digitales	Añadir área TIC (EHR, software de gestión, telemedicina)
🔴 Alta	Teletrabajo	Incorporar dimensiones de trabajo remoto e híbrido
🔴 Alta	Digitalización de instrumentos	Migrar cuestionarios a plataformas web (Google Forms, LimeSurvey)
🟡 Media	Marco normativo	Alinear con MECU, SNCFP y ESCO
🟡 Media	Validación psicométrica	Calcular fiabilidad (alfa de Cronbach) y validez del instrumento
🟢 Baja	Multilingüismo	Preparar versiones en inglés, francés, portugués
