## 7. Dashboard de resultados

El Excel calcula, para cada una de las 12 áreas, la media de las puntuaciones introducidas (1-5) y el número de factores puntuados. La puntuación global del puesto es la media de las 12 medias de área. Es un índice descriptivo: no está validado psicométricamente y mezcla áreas cuya escala mide cosas distintas (frecuencia, relevancia, preferencia, intensidad de requisito), así que conviene leer el perfil por áreas antes que el número global.
